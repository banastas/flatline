flatline runs only on Apple Silicon Macs with macOS 27. It shows CPU load for each Performance and Efficiency cluster, memory pressure the way macOS measures it, and network rates from 64-bit counters. It uses about 0.1% CPU itself.

WHAT IT SHOWS

CPU

Total load with the user/system split, each Performance and Efficiency cluster, a per-core grid and the load average.

MEMORY

App, wired, compressed and cached memory with Activity Monitor's definitions, plus memory pressure and swap.

NETWORK

Live upload and download from 64-bit counters, so no false spikes after 4 GB, with session totals and your active interface.
